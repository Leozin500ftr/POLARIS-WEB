Política de Privacidade

Proteção de Dados

Última atualização: MARÇO de 2026  ·  Versão 1.0

A Polaris Softwares está comprometida com a proteção dos seus dados pessoais. Esta Política de Privacidade descreve como coletamos, utilizamos e protegemos as informações dos usuários da nossa plataforma, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

📋 1. Coleta de Dados Pessoais

A Polaris Softwares coleta exclusivamente os dados estritamente necessários para a prestação dos serviços oferecidos pela plataforma. Os dados coletados incluem:

  • Dados de identificação: nome de usuário fornecido no momento do cadastro.
  • Dados de contato: endereço de e-mail, utilizado para identificação e recuperação de acesso.
  • Dados de autenticação: credenciais de acesso (senha), armazenadas de forma segura.
  • Dados de uso: registros de atividades realizadas na plataforma (logs), para fins de auditoria e segurança operacional.
  • Dados operacionais: informações inseridas pelo usuário durante o uso do sistema, como cadastros de clientes, produtos, pedidos e serviços.

A coleta ocorre no momento do cadastro, do acesso à plataforma e durante a utilização das funcionalidades do sistema.

🍪 2. Uso de Cookies e Armazenamento Local

A plataforma Polaris utiliza armazenamento local do navegador (localStorage) para manter o funcionamento da sessão e preservar preferências do usuário. As informações armazenadas localmente incluem:

  • Sessão de usuário: identificação do usuário autenticado, para manutenção do acesso durante a navegação.
  • Preferências visuais: configuração de modo claro ou escuro (dark mode), conforme selecionada pelo usuário.
  • Dados operacionais: informações cadastradas na plataforma, armazenadas localmente no dispositivo do usuário.
  • Registros de atividade: logs de ações realizadas, mantidos para rastreabilidade e auditoria interna.

Estas informações não são transmitidas a servidores externos e permanecem exclusivamente no dispositivo do usuário. O usuário pode, a qualquer momento, limpar os dados armazenados através das configurações do seu navegador.

⚖️ 3. Direitos do Usuário — LGPD

Em conformidade com o artigo 18 da Lei nº 13.709/2018, o titular dos dados pessoais possui os seguintes direitos, que podem ser exercidos a qualquer momento:

✅ Confirmação e Acesso
Direito de confirmar a existência de tratamento e acessar os dados pessoais que mantemos sobre você.
✏️ Correção
Direito de solicitar a correção de dados incompletos, inexatos ou desatualizados.
🗑️ Eliminação
Direito de solicitar a exclusão dos seus dados pessoais tratados pela plataforma.
🚫 Oposição
Direito de se opor ao tratamento de dados realizado em descumprimento à legislação aplicável.
📦 Portabilidade
Direito de solicitar a portabilidade dos seus dados a outro fornecedor de serviço.
🔒 Revogação do Consentimento
Direito de revogar o consentimento a qualquer momento, mediante manifestação expressa.

Para exercer quaisquer dos direitos acima, o titular poderá entrar em contato com o nosso Encarregado de Proteção de Dados (DPO) pelo e-mail indicado abaixo.
